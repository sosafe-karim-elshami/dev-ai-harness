# /growth

Invoke `harness-growth` for career visibility, IDP tracking, knowledge sharing prep, and growth-focused 1:1 preparation.

## Usage

```
/growth                          — default: visibility audit for the last 2 weeks
/growth idp                      — check IDP goals against recent evidence
/growth talk                     — surface private notes worth presenting; structure a talk
/growth 1:1                      — prep growth agenda for next 1:1 with manager
/growth stale                    — show open PRs and tickets older than 7 days
```

## What this is for

The gap between work done and work made visible is where careers stall. This command surfaces that gap and proposes the minimum action to close it — one Confluence page, one sentence in a review, one RFC with your name on it.

Run it before every 1:1 with your manager. Run it before any performance review window opens.
